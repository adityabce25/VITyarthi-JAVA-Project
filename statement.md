# Project Statement
## Problem Statement
College event information and registrations are often managed through scattered messages or spreadsheets, causing duplicate records and difficulty tracking active events.
## Scope
This project provides a lightweight console-based event and registration manager for a college department or club.
## Target Users
Students, event coordinators, and club administrators.
## High-Level Features
Event CRUD-style management, student registration, cancellation, validation, and reporting through lists.
