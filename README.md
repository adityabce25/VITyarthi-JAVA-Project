# Campus Event Manager
A Java console application for managing college events and student registrations.

## Features
- Add and view events
- Register students for active events
- View registrations
- Cancel events
- Input validation and error handling

## Technologies
Java, OOP, ArrayList, packages, Git/GitHub.

## Run
```bash
javac src/*.java
java src.Main
```
## Testing
Test empty fields, invalid menu input, unknown event IDs, registration after cancellation, and normal CRUD workflow.
